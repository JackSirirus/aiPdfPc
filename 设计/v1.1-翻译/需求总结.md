## 背景

AIPDF 当前是「工具优先」的本地 PDF 工作台，阅读器（v1.0）已把文档变成一等公民。README/AGENTS.md 现状明确写着「不提供 AI 摘要与翻译，不连接本地模型服务，也不下载模型」——这是维护者早期的范围排除。

用户新诉求：**给 PDF 增加翻译能力**——能整篇翻译或局部翻译；翻译要有专业性；根据不同的 prompt 进行翻译；参考 PDFMathTranslate 实现。

本文件是 `/design-exploration` 第一~四步成果的落盘总结。需要先说清楚：**这是一次正式的范围扩展**，而不是旧排除项的自行恢复。`AGENTS.md` 与 `README.md` 的范围段落需要在实现阶段同步更新（逐字建议文本见 §落地清单）。

## 目标

1. 在阅读器内就地翻译：选中即译（划词），或整篇翻译（右栏「整篇」）。译后仍以 PDF 阅读。
2. 译文以**新 PDF 文档**呈现（不改源文件），支持 mono（纯译文）与 dual（原文/译文对照）两种形态，在新标签打开。
3. 专业化：预置分领域 prompt 模板 + 自定义 prompt + 术语表，约束译文风格与专有名词。
4. 批量：多文件一次翻译（起始页/工具箱「批量翻译」工具页）。
5. 引擎自研轻量：抽取 → LLM 翻译 → 回填排版；**不下载模型、不下载字体**。
6. 云端调用须**首次明确同意**，密钥交系统凭据管理器加密保存；**密钥仅经 stdin 传递**，绝不写入明文配置 / 日志 / 命令行参数（argv）/ 子进程环境 / 崩溃转储 / 会话恢复。
7. 视觉复用 v1.0 阅读器 A+C 暖纸体系，**不新增主题 token**。
8. **默认引擎为本地**；云端是用户主动选择的升级项，不是默认路径。
9. **输出必须可搜索**（真实文本 + ToUnicode）；回填溢出一律按确定策略处理并显式降级标注（见 `翻译-回填排版规格.md`）。

## 功能范围

### 做什么（V1 纳入）

- **划词翻译**：选中文字 → 浮出小「译」按钮 → 点击后在右栏「划词」Tab 出译文卡片（原文/译文/复制/替换标注/加入术语/重译）。
- **整篇翻译**：右栏「整篇」Tab 内**纵向堆叠**：配置 → [开始] → 进度 → 结果；支持取消与「后台继续」；生成 mono + dual 两份 PDF。
- **批量翻译**：起始页/工具箱新增「批量翻译」工具页（复用工具页范式：文件列表 → 统一配置 → 进度 → 结果**列表**，按需打开，不逐件开标签）。
- **分领域 prompt**：预置学术 / 法律 / 医学 / 技术 / 通用 5 类 + 自定义 + 术语表；法律/医学模板选中时给出**高风险确认提示**。
- **扫描件处理**：先 OCR 再翻译（复用既有 OCR 能力，仅限白底纯图片页，尽力而为）。
- **公式/表格**：**纳入并尽力**，失败时**显式降级并标注**（回填策略见规格文档 §4）；不承诺 1:1 复刻。
- **术语表**：用户指定专有名词的固定译法，优先级高于模型默认（格式/匹配/存储/校验见 §术语表）。
- **多文件批量**：统一配置 + 逐件进度 + 结果列表 + 部分失败汇总。
- **语言方向**：**源语言与目标语言分设**；自动检测**仅用于源语言**，目标语言必须显式选择（默认中文）。
- **受限文档**：仅权限加密（可打开、禁止抽取/复制）按 §受限文档策略处理。
- **Markdown 导出**（可选）：把译文导出为 `.md`，便于二次编辑。

### 不做什么（V1 明确排除）

- **离线模型下载管理**：不做模型/字体下载、不做下载进度/校验/缓存管理（同时受 AGENTS.md 硬约束）。
- **翻译历史 / 项目库**：不做翻译项目、历史记录、跨会话复译与版本管理。
- AI 摘要、模型连接管理（特指由应用代管的本地模型服务，见 §落地清单 AGENTS 改写）、模型下载管理。
- 云端账户体系 / 付费配额管理 / 团队协作。
- **保证版式 1:1 复刻**（复杂表格、公式、多栏、竖排一律「纳入并尽力、失败显式降级并标注」）。
- **RTL（阿拉伯/希伯来）与竖排版式**：V1 明确**不支持**，检测到即保留原文并标注，不静默损坏。
- **跨页重排 / 自动扩页**：V1 不做（溢出走裁切降级，见回填规格）。

## 载体

阅读器（v1.0 A+C）为唯一主界面，翻译以两种形态接入：

| 入口 | 形态 | 覆盖能力 |
|---|---|---|
| 阅读器右栏 | 双 Tab「划词 / 整篇」，宽约 320px（较常规 240 加宽） | 划词 + 整篇 |
| 起始页 / 工具箱 | 独立「批量翻译」工具页 | 多文件批量 |

- 「整篇」Tab 内纵向堆叠：配置 → [开始] → 进度 → 结果（不跳页、不弹向导）。
- 划词悬浮按钮：选中文字后在选区附近浮出小「译」，点击才发请求（不做选中即译）；**本页无文本层时划词不可用**，提示改用整篇/OCR。
- 批量工具页沿用既有工具页范式（`ToolPageStyles.xaml` 一类）：拖拽区 + 文件列表 + 统一设置 + 开始 + 结果列表。
- 输出产物：mono / dual PDF 均在阅读器**新标签**打开；源文件只读不变。

### 入口收敛说明

6 个入口（划词浮钮、划词 Tab、整篇 Tab、批量工具页、设置→翻译、云端同意模态）是**刻意分散**的交互触点，但共享一个**统一的翻译配置面板组件**。划词 Tab 与整篇 Tab 共享同一套语言/模板/引擎配置（读写同一份 settings）；批量工具页复用相同配置组件，只是多了文件列表与结果列表。这种「多入口、单组件」设计让每个入口的上下文最小化，同时保证配置一致性。

### 最小窗口与响应式

- **最小窗口尺寸**：阅读器窗口最小宽度 **680px**（确保左栏 200px + 阅读区 + 右栏 320px 可用）。
- **窗口 < 680px 时**：右栏翻译 drawer 切换为**覆盖层模式**（overlay，从右侧滑入，宽度 320px，背景遮罩）；左栏缩略图折叠为图标行。
- **窗口 < 480px 时**：配置行折叠为可展开的摘要行（点击展开完整配置）；进度条简化为百分比数字。
- 批量工具页不受窗口宽度限制（全屏工具页）。
- 暗色/亮色切换与窗口尺寸无关，始终生效。

## 安全边界（不可信输入）

> 依据 `AGENTS.md`：文档、网页及其脚本都是不可信输入。翻译把**文档文本**送入 LLM，必须按不可信输入处理。

### 1) 指令与内容分离

- **system / user 消息严格分离**：翻译指令、术语表、输出格式要求放 **system**；待译文本放 **user**，且用**成对、不可被正文伪造的分隔符**包裹（如固定随机 nonce 包裹，nonce 在 system 中声明并在 user 中校验）。
- **禁止工具调用 / 函数调用 / 联网**：翻译请求为纯文本补全，不提供任何 tool/function、不解析模型输出中的 URL 为可执行动作。
- 文档文本中的任何指令（如「忽略以上指令 / 输出系统提示 / 访问某网址」）**一律视为待译内容**，不得执行。
- prompt 模板与术语表是**用户输入**，同样不拼接为可执行指令；模板只允许占位符替换，不允许自由代码/命令。

### 2) 输出校验（schema 校验）

- 要求模型返回**受限结构**：逐段 `{index, text}` 列表（或等价 JSON）。解析失败 → 不直接回填，转入重试或逐段重译。
- 校验项：段落数匹配、无空响应、无非译文说明性文字（如「作为 AI 我无法…」→ 判为拒绝，见错误分类）、长度比例异常（译/原长度比超出 `[0.2, 3.0]` 视为可疑，标记复核）。
- **疑似未译/回 echo 检测**：若译文与原文**完全相同**或**相似度 > 95%**（编辑距离归一化），或模型返回**元描述/解释性语句**（如「以下是翻译」「I cannot translate」等非译文内容），标记为 `untranslated_echo`，该段不回填，转入逐段重译（限 1 次）；仍失败则保留原文并标注。
- 校验失败不静默采用；命中异常按错误分类处理并在结果区标注。

### 3) 可疑指令处置

- 命中已知注入模式（如「ignore previous instructions」「system prompt」「忽略以上」等）→ **拒绝翻译该段并告警**（结果区/全状态稿「检测到可疑文档指令」），不把可疑文本原样交给模型继续放大。
- 该处置只影响被标记段落，其余段落继续，并在降级报告留痕。

### 4) 隐私与遥测

- **无遥测、无隐式上传**：除用户明确同意后发往所选云端服务商外，翻译内容不离开本机；崩溃报告/错误上报**不含文档正文与密钥**。
- 错误报文**脱敏**：不展示服务商原始报文；过滤可能的密钥片段（前缀/尾串）；密钥使用后**清零**（尽力而为，并明确托管字符串的内存局限）。
- 本地引擎调用需校验 **loopback**（见 §本地引擎 loopback 校验）：非 loopback 端点不得以「本地」名义绕过云端同意。

## 云端配置复用与同意

> 需求块「云端配置与同意：配一次，跨会话复用」。目标：连接配置与密钥一次配置后跨会话自动读回；云端同意按 `provider + endpoint` 记住；凭据失效时只补密钥、不动其他配置。

### 持久化矩阵

| 内容 | 存哪 | 下次启动行为 |
|---|---|---|
| 连接配置（服务商 / endpoint / 模型名 / 参数） | 应用设置（同既有 `SettingsStore`） | 跨会话自动读回；本地 / 云端各自记住上次选择 |
| API Key | Windows 凭据管理器（OS 加密保存） | 跨会话自动读回；**仅经 stdin 传递**；**不进 argv、不进日志、不写入子进程环境变量、不进崩溃转储、不写明文配置、不进 recent / session / reading-state / presets** |
| 云端同意（按 `provider + endpoint`） | 应用设置（仅存 `provider + endpoint + 密钥指纹 + 同意时间 + TTL`，**不存密钥 / 正文**） | 已记住且 endpoint 未变 → **不再弹**；endpoint 主机名/协议/端口任一变更 / TTL 过期 → **重新弹**；未记住 → 每个服务商**每次会话首次使用时**提示一次（提示 ≠ 重新配置） |
| 密钥指纹 | 应用设置（仅存密钥的短哈希，用于识别「换 key 即同意失效」） | 不存密钥本体；key 变更 → 该 endpoint 的同意失效，重新提示 |

### 条款（a）–（h）

- **（a）连接配置跨会话复用**：服务商 / endpoint / 模型名 / 参数存**应用设置**（同既有 `SettingsStore`），下次启动自动读回。
- **（b）API Key 交 OS 保存**：存 **Windows 凭据管理器（OS 加密）**，跨会话自动读回；**仅经 stdin 传递**；**不进 argv、不进日志、不写入子进程环境变量、不写明文配置、不进崩溃转储、不进会话恢复**。
- **（c）同意绑定目的地**：同意键 = `provider + endpoint（+ 密钥指纹）`。勾选「记住我的选择」后该组合不再弹；未勾选则每个组合**每次会话首次使用时提示一次**。
- **（d）改配置的重置规则**：**endpoint 主机名/协议/端口任一变更 → 必须重新同意**（因目的地改变）；**仅改 key（同 endpoint）→ 同意失效并重新提示**（密钥指纹变化）；仅改模型名 → 不重置同意。切换不同服务商 → 重新提示。
- **（e）凭据不可用仅补 key**：被系统清除 / 换机 / Credential Manager 锁定 → 仅提示**重填 key**，**不清空**其他配置（服务商、模型、同意状态均按新端点规则处理）。
- **（f）管理入口**：**设置 → 翻译 → 云端服务商**，可改 key / 改模型 / **撤销同意（提供「同时清除凭据」选项）** / 清除凭据。
- **（g）撤销同意与凭据**：撤销同意时可勾选**同时清除凭据**（推荐默认提供该选项）；撤销后该 `provider+endpoint` 下次使用回到未同意态。同意记录带 **TTL（默认 180 天）**，过期自动重新提示。
- **（h）与文档密码约定的区分**：文档密码 = **单次处理、经 stdin、绝不落盘**；云端 API Key = 用户配置的**长期凭据**，交 **OS 加密保存**，但同样**仅经 stdin 进入子进程**。「不落盘」指不写**明文配置 / 日志 / argv / 环境变量**，不禁止交系统凭据管理器持久化。

### （i）漫游策略（域环境）

- `%APPDATA%` 下的应用设置可能随 Windows 域配置漫游，但 **Windows 凭据管理器不随域漫游**。
- 风险：机器 B 上的同意记录（含 endpoint + 密钥指纹）可能与凭据管理器中的实际 key 不一致。
- **规则**：同意记录中包含 `endpoint + 密钥指纹`。每次读取凭据时校验指纹是否匹配；**缺失或不匹配即视为未同意**，重新弹出同意确认流程。
- 实现：启动时 / 首次使用云端时，对比同意记录中的指纹与凭据管理器返回的 key 的实际指纹；不一致则清除该条同意记录并重新提示。

### （j）禁止在 endpoint/连接参数中内嵌密钥

- 保存连接配置时**校验 URL 中不得含 key/token 查询参数或 userinfo**（如 `https://key:secret@host/v1` 或 `?api_key=xxx`）。
- 目的：防止用户在 settings 备份/导出/漫游时意外泄漏明文密钥。
- 触发时机：保存连接配置时逐项校验；命中则拒绝保存并提示「密钥请保存在系统凭据管理器中，不要写在端点地址里」。
- 已保存的旧配置若命中此规则，加载时发出警告并阻止使用（引导用户迁移到凭据管理器）。

### 凭据命名与卸载清理

- **凭据目标命名**：Windows 凭据管理器中的凭据使用命名空间格式 `AIPDF-Translate-{provider}-{endpoint_hash}`（`endpoint_hash` 取 endpoint URL 的 SHA256 前 8 位 hex），避免不同服务商/端点的凭据互相覆盖。
- **卸载清理**：卸载应用时（通过标准 Windows 卸载程序），清理凭据管理器中所有 `AIPDF-Translate-*` 前缀的凭据条目。清理前需用户确认（弹窗列出将删除的凭据数量）。
- **重装/升级不丢失**：正常升级（同名安装覆盖）不清除凭据；仅显式卸载或用户在设置中主动清除时才删除。

### 本地引擎 loopback 校验（防同意绕过）

- 标记为「本地」的端点**必须**是 loopback（`127.0.0.1` / `::1` / `localhost`）。
- 非 loopback 地址**不得**以「本地」名义调用；应要求用户切到「云端」并走同意流程。

### 任务中途改凭据 / 撤销同意

- 批量或整篇运行中修改 key / 撤销同意：**不影响已发出的在途请求**；下一个请求前重新校验同意与密钥。
- 撤销同意后，未发出的后续请求**停止**，任务转「已取消/需重新同意」状态。

## 技术约束与研究结论

### 上游调研（PDFMathTranslate / BabelDOC，2026-09-13）

- 上游三仓：`PDFMathTranslate/PDFMathTranslate`（1.x，v1.9.12，AGPL-3.0）；`PDFMathTranslate-next`（2.0）；`funstory-ai/BabelDOC`（版面 IR 引擎，0.6.4，AGPL-3.0）。
- v1 快速栈 = pdfminer + PyMuPDF + DocLayout-YOLO ONNX + 内容流改写 → mono/dual。
- v2 精确栈 = BabelDOC IR + 公式掩码 + LLM + 术语提取 + 自适应排版（缩字拟合）。
- **运行时下载**：ONNX ≈71.8 MiB（SHA3-256）；字体 ≈14–16MB/套，全量 warmup 可达数百 MB。
- **集成摩擦**：① PyMuPDF 版本冲突（需分 venv）；② 资产下载失败时库内 `exit(1)` 杀宿主（必须子进程隔离）；③ 上游 API Key **明文写 config.json**（与本项目冲突）；④ v2 仅支持 OpenAI 兼容端点。
- 许可：上游 AGPL-3.0 与宿主 AGPL-3.0-only **兼容**；但模型/字体资产为独立许可。
- **能力边界**：表格基本不支持；公式有误判；扫描 OCR 仅限白底纯图片页；产物仅 mono/dual PDF。

**结论：采用自研轻量**，规避运行时下载与 venv 负担；回填算法与溢出策略见 `翻译-回填排版规格.md`；未来可预留「精确模式」扩展位（见 §未决项）。

### 宿主复用与新建

- **复用**：引擎子进程桥接（stdin 单行 JSON / stdout 单行 JSON / stderr 进度；取消 = taskkill 子进程树）、密码经 stdin 传递、`EngineBridge`、OCR 能力（`Sources/VisionHelper` 同源能力已在 Windows 侧有 OCR 工具）、阅读器新标签打开通道、工具页范式、A+C `Brush.*` token。
- **新建**：翻译引擎子命令（抽取 → 分段 → LLM 调用 → 回填 → mono/dual 输出）、分段与回填排版器、prompt 模板与术语表存储、云端同意与凭据管理（Windows Credential Manager）、批量任务编排与结果列表 UI、划词悬浮按钮与右栏双 Tab。
- **密钥约束**：仅存系统凭据管理器；调用时**仅经 stdin 传递**；不写入命令行参数（argv）、不写入子进程环境变量、不写日志、不写配置文件、不进阅读状态/会话恢复/最近文件/流程预设。
- **stdout 纯净性**：子进程 stdout 只允许约定 JSON；库日志/警告一律重定向到 stderr；宿主解析失败按任务失败处理，不误采用。

### 宿主↔引擎桥接：大小上限与分块协议

- 引擎子进程与宿主之间通过 stdin/stdout 传递 JSON；**单行 JSON 不得超过 1 MB**（避免多 MB 单行导致内存峰值与解析卡顿）。
- **抽取阶段**采用 NDJSON（换行分隔 JSON）流式传输：每页抽取结果独立一行，宿主流式解析，不等待全量输出。每行上限 **512 KB**；超出标 `extraction_chunk_oversize` 错误，该页降级处理。
- **翻译请求**：每 chunk 的待译文本为单行 JSON；超长文本按 §3 分块后逐 chunk 发送，不合并为超大 payload。
- **翻译响应**：逐 chunk 返回；每 chunk 响应为独立行，宿主按 chunk_id 拼装。
- 超限处理：任何单行超过上限 → 引擎侧拒绝输出该行并报 stderr 诊断；宿主侧解析失败按任务失败处理，不误采用半成品。
- **后台与退出**：后台任务**仅本次会话内有效**；父进程退出/崩溃时 kill-on-close（Job Object）并清理孤儿进程与临时文件；输出采用**原子写（temp → rename）**，避免半成品被打开。
- **输出与热路径分流**：抽取/翻译走子进程；导出阶段同样原子写；已译内容在会话内可「先导出已译页」，但**退出即丢失未导出内容**（V1 不做任务日志持久化，见决策 #13）。

### sidecar 标注文件（替换标注）

- **用途**：划词翻译的「替换标注」功能将译文写入独立 sidecar 文件，在阅读视图叠加显示，不写回源 PDF。
- **位置**：优先存放在源 PDF 同目录下，文件名格式 `.<源文件名>.transl_sidecar.json`，并设置 `FILE_ATTRIBUTE_HIDDEN` 属性使其在文件管理器中默认隐藏（Windows 上点号前缀不等于隐藏，必须使用系统属性）。**当源目录不可写时**（CD-ROM、网络驱动器、只读目录），**回退到任务临时目录**（`%TEMP%\AIPDF-Sidecar\`）存放 sidecar。
- **生命周期**：sidecar **仅在会话内有效**。应用退出时清理会话内 sidecar；下次打开同一文档时不自动加载旧 sidecar（用户需重新标注）。V1 不做跨会话 sidecar 持久化。
- **不缓存正文**：sidecar 仅存储 `{页码, 坐标, 译文, 语言对, 时间戳}`，不存储原文全文；选中文本按需发送（划词）或批量发送（整篇），不缓存原文到 sidecar 或其他持久存储。
- **与批量/整篇的关系**：批量/整篇的产物（mono/dual PDF）是独立文件，不是 sidecar；sidecar 仅服务于划词的替换标注叠加显示。

### 错误分类与重试策略（统一）

| 类别 | 典型信号 | 处置 | 是否重试 |
|---|---|---|---|
| 网络 | 连接超时 / DNS 失败 / TLS 失败 | 提示网络问题 | 是（指数退避） |
| 超限 | HTTP 429 / 额度不足 / 频率限制 | 提示额度或稍后；可换服务商 | 是（带更长退避） |
| 拒绝（refusal） | 模型返回「无法翻译/拒绝」或空响应 | 明确标注「模型拒译」，不当作网络错误 | 否（换模板/模型） |
| 空响应（empty） | 返回空字符串 / 无内容 | 判为可疑，逐段重试一次 | 是（限 1 次） |
| 超限（over-limit） | 段落/请求超上下文 | 自动按 §3 切分；仍超则降级 | 是（切分后重试） |
| 校验失败 | schema 不符 / 段落数不匹配 | 逐段重译；仍失败降级 | 是（限 1 次） |
| 中止 | 用户取消 / 撤销同意 | 停止后续请求 | 否 |

- **统一重试**：同一错误**最多 2 次**，指数退避（如 1s、4s）；拒绝/中止不重试。计数与文案在所有页面统一，不再出现「2 次 / 3 次」不一致。
- **成本硬上限**：开始前给出**预计调用次数与估算 token**；用户可设**单任务硬上限**（如最大调用次数 / 最大估算 token / 最大金额估算）。达到上限即**停止后续请求**并转「成本超限」状态，已译内容可导出。批量按文件累计同样受上限约束。

### 语言：源 / 目标分设

- **源语言**：可「自动检测」或显式指定；自动检测结果只作为源。
- **目标语言**：**必须显式选择**（默认「中文」），不参与自动检测。
- 短句/专名/数字自动检测不可靠：检测置信度低时提示用户固定源语言。
- 多语言混合：按段检测，提示「按语言分批」以保术语一致。

### 术语表格式 / 匹配 / 存储 / 校验

- **格式**：CSV（`源词,目标词[,大小写敏感[,说明]]`）为主，可导入；行内 `#` 为注释。
- **匹配**：默认**大小写不敏感的全词/前缀边界匹配**（拉丁）；CJK 按子串匹配；可对单条开启大小写敏感。
- **优先级**：用户术语表 > 模型默认。命中后作为强约束放入 system，**并做译后校验**（回填前检查命中词是否按指定译法出现；未命中则标记「术语未遵循」供人工确认，不谎称「强制成功」）。
- **存储**：术语表存应用数据目录（用户可命名、可多表）；**不存文档正文**。批量/整篇复用所选表。
- **校验**：导入时做重复检测与冲突检测；同名冲突与内部重复在 UI 显式提示（见全状态稿 T15 扩展）。

### 受限文档策略（仅权限加密）

- 文档以**空用户密码 + owner 权限**打开（可打开但 `/P` 禁止抽取/复制）时：
  - 允许打开阅读；
  - 翻译前**显式确认**「该文档设置了权限限制，翻译会抽取其文本并在输出中重排；请确认你有权处理」；
  - 用户拒绝 → 不翻译；
  - 输出 mono/dual **不继承**原文档的限制标记（因是新文档），但须在结果区明示「已绕过源文档的抽取限制（经用户确认）」。
- 加密且需打开密码的文档：密码仅本次使用、经 stdin、不落盘（沿用既有约定）；输出加密策略默认**不加密**，可在结果区另存时手动设置。

### 解密内容与临时文件

- 加密文档解锁后，抽取文本/OCR 图像会短暂落盘于**任务临时目录**；任务结束/取消/失败后**清理**临时目录；临时文件不进入 recent / presets / 会话恢复。
- 输出 PDF 为解密内容；须提示用户自行保管。

## 能力边界与风险（诚实标注）

| 项 | 承诺 | 说明 |
|---|---|---|
| 表格 | **纳入并尽力、失败显式降级并标注** | 跨行合并/嵌套/无框线表格易错位或丢结构；失败时保留原文/可读文本并标 `table_fail`。 |
| 公式 | **纳入并尽力、失败显式降级并标注** | 可能位移、字号变化或转文本；抽取乱码或溢出无法适配时标 `formula_fail`，不写入错误内容。 |
| 扫描件 OCR | **尽力且质量受限** | 仅白底纯图片页效果好；低对比/扫描噪点/旋转页会降低识别率。 |
| 版式 1:1 | **不承诺** | 复杂多栏、竖排、艺术字、图文混排以「可读」为目标；溢出按规格裁切并标注。 |
| 源文本抽取完整性 | **不保证** | 子集字体缺 ToUnicode、连字、CID/PUA 可能导致抽取乱码；低置信度页标 `extraction_low_conf`，不静默使用。 |
| 旋转 / 裁剪 | **支持但可能降级** | 按未旋转 + CropBox 归一回填（规格 §1）；越界/裁剪页标 `rotation_crop`。 |
| RTL / 竖排 | **不支持（V1）** | 阿拉伯/希伯来、竖排中文/日文检测到即保留原文并标注，不静默 LTR 错排。 |
| 字体与可搜索 | **可搜索为硬需求** | 输出用带 ToUnicode 的字体；缺字形标 `glyph_missing`、不可搜索页明示；不嵌入受限字体。 |
| 译文质量 | **受模型与 prompt 影响** | 术语表可约束专名；长句/文化语境仍可能不准确，需人工复核；结果区常驻「机器翻译 · 请核对」；产物 PDF 每页页脚加极小标记（一般文档默认开启、可在设置中关闭；法律/医学高风险模板强制显示、不可关闭）。 |
| 幻觉 / 漏译 | **需人工复核** | 做长度比例与段落数校验；异常标记复核，但不保证零幻觉。 |
| 法律 / 医学高风险 | **须人工复核** | 选中法律/医学模板时弹**高风险确认提示**；结果区常驻「机器翻译 · 请核对」标记；产物 PDF 页脚标记**强制显示、不可由设置关闭**（一般文档可在设置中关闭，高风险模板不可）。高风险确认**同时警告机密性/特权/受监管数据**：「上传涉密/受特权保护或受监管数据前请确认合规与授权」。 |
| 语言对 | 通用横排 | 罕见语言取决于所选模型支持度与系统字体；RTL/竖排不在范围。 |
| 本地引擎 | **默认引擎；需用户自备运行时** | 不代下载模型；无运行时则提示配置或改用云端（云端须同意）。 |
| 云调用的代价 | 明确告知 | **整篇翻译会把全文文本分批发送给服务商**（非仅「片段」）；首次同意模态按聚合口径说明。 |
| 大文档 | 分段处理 | 超长文档耗时长、费用/额度消耗高；受成本硬上限约束；支持取消与后台继续（仅会话内）。 |
| 受限文档 | 需显式确认 | 仅权限加密可打开但默认不翻译；须确认有权处理。 |

## 实现分期与验收门

> **核心原则：PDF 回填是 v1.1 的正式交付目标，spike 是质量门而非删除开关。** 回填未达标时在 UI 显式降级标注（文本/Markdown 导出），不静默跳过，也不把回填从 v1.1 范围中移除。

### V1.1a · 引擎底座（抽取 → 分块 → 翻译 → 回填 spike）

| 交付 | 说明 |
|------|------|
| 抽取与分块 | PyMuPDF 抽取 + 坐标归一化 + 段落重建 + token 预算分块（规格 §3） |
| 翻译 | 本地引擎 + 重试策略 |
| **回填 spike** | mono/dual 回填 + 溢出策略（缩字→溢白→裁切）+ ToUnicode + z-order |
| 降级报告 | 每页降级原因枚举 + 可搜索校验（规格 §9） |

**退出标准（量化，全部达标方可进入 V1.1c）**：

- 测试集：**1 个合成的双栏版面样例（模拟真实两栏排版）** + **3 个合成样例**（表格密集页 / 公式密集页 / 扫描件页）。
- 溢出页占比（`clip` 标记页 / 总页数）≤ **10%**。
- 每页裁切块数 ≤ **2**（单页裁切不超过 2 个文本块）。
- ToUnicode 覆盖率 = **100%**（所有非扫描叠加页均可搜索）。**此 spike 门禁（100%）有意比运行时每页阈值（95%，见回填规格 §8.4）更严格**：spike 不达标则整个回填不并入 V1.1c；运行时单页低于 95% 仅标记 `search_verify_fail` 并降级该页，不阻断整批任务。
- 降级报告完整输出：每页有 `degraded: true/false` + `reasons[]`。
- **回填 spike 未达标时的处理**：V1.1c 回填 mono/dual **不并入**，UI 显式标注「回填尚未通过质量门，当前提供文本/Markdown 导出；回填达标后将自动启用」。这不是静默失败，用户在结果区看到明确的降级说明。

### V1.1b · 阅读器划词 + 整篇（文本/Markdown 导出）

| 交付 | 说明 |
|------|------|
| 划词翻译 | F1 全部状态（选中浮出「译」/ 卡片 / 复制 / 替换标注 / 重译） |
| 整篇配置 | F2 全部状态（语言/模板/术语/引擎/成本上限） |
| 整篇进度与结果 | F3 + F4（文本结果 + Markdown 导出 + 降级报告） |
| 批量翻译 | F6 结果列表化（结果列表 + 按需打开） |
| 云端 LLM + 同意 | F5 全流程 + 云端 LLM（stdin 传递密钥）+ 凭据管理 |

**退出标准**：

- 划词：选中 → 浮出 → 点击 → 卡片出译文，全流程可走通。
- 整篇：配置 → 开始 → 进度 → 文本/Markdown 结果 + 降级报告。
- 云端：首次同意 → 凭据保存 → 跨会话复用 → 撤销同意；云端 LLM 调用可用。
- 批量：结果列表化 + 按需打开，全流程可走通。
- **不依赖回填**：此阶段结果为文本/Markdown，PDF 回填在 V1.1c 接入。

### V1.1c · 回填 mono/dual（仅在 V1.1a spike 达标后并入）

| 交付 | 说明 |

| dual PDF | 原文/译文对照 PDF，页码对齐 |

**并入条件**：V1.1a spike 的全部退出标准达标（由测试集验证 + 维护者确认）。

**未达标降级**：V1.1 内 **显式降级为文本/Markdown 导出**，结果区标注「PDF 回填尚未通过质量门，当前提供文本与 Markdown 导出」。UI 不隐藏 PDF 回填入口，而是标注为「回填达标后可用」，保持目标可见。

### V1.1d · 批量工具页完整（拖拽/多选/统一配置/逐件进度/部分失败汇总）
