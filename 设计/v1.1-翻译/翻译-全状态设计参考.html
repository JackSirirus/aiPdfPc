一、划词翻译
右栏「划词」Tab。核心：不给用户「什么都没发生」的错觉——空态说清楚、加载有骨架、错误给出口。

T03错误

划词 · 翻译失败（重试）

网络/额度/模型返回异常。错误就地内联，同时给主出口「重试」与次级出口。

重试最多 2 次（指数退避）；仍失败则保留错误态。

交互出口

  • 重试：就地对同一选区重新翻译（限 2 次）。
  • 更换服务商：打开设置切换端点（需重新同意）。
  • 复制原文：失败也能带走内容，避免卡死。

  • 关闭：丢弃本次结果，回到配置态。

三、云端调用
云端相关的前置与失败态。原则：密钥只交系统凭据管理器加密保存（不写明文配置 / 日志 / argv），拒绝即回退本地；配置复用与同意的细节见「七、云端配置复用」。
T09未配置

云端 · 未配置密钥

用户选择云端但尚未保存 API Key。密钥只进系统凭据管理器，输入框不回显明文。
划词整篇
⚠ 尚未配置云端密钥，无法开始翻译。
API Key
保存到系统凭据管理器（OS 加密）；不写明文配置、不写日志、不进命令行。

  • 打开设置：完整设置页填写端点 + 密钥。
  • 未保存密钥时开始按钮禁用并说明。

五、边界情况
在开始前或运行中提前暴露限制，避免用户跑到一半才踩坑。
T13边界

超长文档 / 大文件（分段与耗时）

页数或体积超过建议阈值。开始前提示分段处理、耗时与费用，并允许缩小范围。
划词整篇

交互出口

  • 仍要开始：接受耗时，进入进度。
  • 只译当前页区间：缩小范围以控制时间与费用。
  • 超长任务默认支持后台继续与取消。

七、云端配置复用
「配一次，跨会话复用」的异常与恢复态。原则：连接配置与同意不动，凭据问题只补 key；换服务商才重新同意。

划词整篇

  • 不因凭据失效清空服务商、模型或同意记录；不重复弹同意。
