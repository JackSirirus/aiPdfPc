# PDF 翻译 · 回填排版规格

> 版本：v1.1（设计基线）
> 日期：2026-09-13
> 状态：设计规格（配合《需求总结.md》《翻译-设计稿.html》《翻译-全状态设计参考.html》）
> 适用：`backend/engine.py` 翻译子命令的「回填排版」阶段（mono 纯译文 / dual 对照）
> 原则：**不用机器学习版面模型**（V1 仍自研轻量）；**不下载模型与字体**；源文档只读；不以黑框充当删除；输出必须可搜索。

---

## 0. 范围与目标

本规格定义「把译文写回页面」这一阶段的**可执行规则与参数**，消除「V1 纳入公式/表格版式」却「不保证」的自相矛盾：V1 的承诺是 **纳入并尽力、失败显式降级并在产物与结果区标注**，而不是保证 1:1 复刻。

回填的输入、输出与不变量：

- 输入：每页的文本块列表（含归一化坐标、字号、字体名、样式）、翻译分块结果（chunk → 译文）。
- 输出：mono / dual 两份 PDF，**文本可提取**（可搜索、可复制），原文本保持只读。
- 硬不变量：
  1. 所有几何计算在**未旋转 + CropBox 相对**坐标系内完成（见 §1）。
  2. 原文本块被**真实移除**后再写入译文，不得残留导致「搜到原文」（见 §6）。
  3. dual 对照满足 `原文页 N ↔ 译文页 N`，缺页补空白（见 §7）。
  4. 任何未达成的效果都必须在**每页降级报告**中留痕（见 §9）。

> V1 **不做**：跨页重排（一段译文自动流到下一页）、自动扩页、1:1 版式、竖排/RTL 版式、机器学习版面检测。这些一律走降级标记。

## 1. 坐标归一化（/Rotate 与 CropBox）

**问题**：PDF 同时存在 `MediaBox`、`CropBox`、`/Rotate`。扫描件常见 `CropBox ≠ MediaBox` 且带非零偏移；v1.0 已有裁剪工具，裁剪后 `CropBox` 就是可见区。若直接用原始坐标回填，文字会跑到裁剪区外、或整页旋转 90°。

**规则：所有回填按「未旋转 + CropBox 相对」坐标。**

定义（`W_crop`、`H_crop` 为 CropBox 宽高）：

1. 读到页面后，记 `θ = page.rotation ∈ {0, 90, 180, 270}`、`crop = page.cropbox`、`media = page.mediabox`。
2. 进入抽取前，**临时把页面旋转归零**（等价于在归一化空间工作）：所有块坐标记为相对 `crop` 左上角、未旋转的坐标 `(x, y)`，单位为 PDF 点（1/72 inch）。
3. 归一化变换（概念式，非实现代码）：
   - 平移：`x' = x - crop.x0`，`y' = y - crop.y0`。
   - 旋转：按 θ 用标准旋转矩阵归一化到「未旋转」朝向；θ=0 无操作，θ=90/180/270 分别做对应旋转（逆时针）。
   - 存储：每个块保存 `rect_norm = (x0', y0', x1', y1', θ)`，`θ` 仅作还原用，布局计算只用去旋转后的 `(x0', y0', x1', y1')`。
4. 写回时对 `rect_norm` 施加**逆变换**，得到当前页面实际绘制坐标；若 θ≠0，绘制基线与文本框同样旋转。
5. 边界守卫：若某块归一化后与 CropBox 边界相交、或越出 CropBox，标 `rotation_crop` 降级，该块**不做溢出自适应**，仅在被裁剪的可见区内尽量排放，并写入降级报告。
6. `CropBox` 与 `MediaBox` 偏移不为零时，**不得**以 MediaBox 原点做回填；页面「可见区」一律取 CropBox。

**参数**：坐标单位点；旋转取值离散四档；归一化后所有块必须落在 `[0, W_crop] × [0, H_crop]` 内，否则触发 `rotation_crop`。

**对应审查**：墨菲 #2、#23；对抗性 #5（几何/坐标）。

## 2. 块检测与阅读序

**抽取**：PyMuPDF `page.get_text("dict")`，层级为 `blocks → lines → spans`；只保留 `type==0`（文本）块，图像块（`type==1`）单独记录为「遮挡参考」，不参与翻译。

### 2.1 去连字（dehyphenation）

行尾连字符换行需要拼接，规则（同时满足才拼接）：

- 行末为 `-`（半角连字符，非 `–`/`—`/软连字符 U+00AD 之外的破折号）；
- `-` 前一个字符为字母，`-` 后一行首字符为**小写字母**；
- 两行属于同一段落候选（见 §2.3）；
- 拼接后整词不构成明显非法形态（不做词典校验，V1 仅做形态规则）。

不满足则**保留连字符**并另起，避免把「well-known」这类词误接。遇未知语言或全大写文档，去连字关闭（配置项 `dehyphenate=false`）。

### 2.2 多栏检测与列内排序

1. 对页面内文本块的 `x` 区间做投影，找**列间空白带**（连续 x 区间内无任何块覆盖，宽度 ≥ 24pt 且跨越页面高度 ≥ 55%）。
2. 由空白带切出列；每块归入其水平中心所在的列。
3. 若找不到任何宽度达标的空白带 → 视为**单栏**（含跨栏标题、通栏段落）。
4. **列序**：LTR 文档从左到右；RTL 文档 V1 不承诺（见 §2.4）。
5. **列内序**：按 `y0` 升序；`y0` 近似相等（差 < 3pt）时按 `x0` 升序。
6. 阅读序键：`sort_key = (column_index, round(y0 / 3), x0)`，稳定排序保证确定性。
7. 通栏块（横跨多列，如标题/表格）单独成「区块」，按 `y0` 插入列序之间：区块 y0 小于某列首块 y0 时，区块先于该列。

### 2.3 段落重建

同一段落候选判定（同时满足）：

- 同列；
- 垂直间距 `gap` 满足 `gap < 1.6 × line_height`（`line_height` 取两行字号较大者 × 1.2）；
- 字号差 ≤ 1.5pt 且无加粗/斜体切换；
- 不满足上述任一条 → 新段落；首行缩进明显（x0 比正文左边界大 ≥ 1.5 字符宽）→ 新段落。

段落是**翻译分块的基本单位**（见 §3），也是回填时的「文本块框」来源。

### 2.4 明确不支持（降级而非静默损坏）

- **竖排（vertical writing）**：检测到文字方向为竖排（`line["dir"]` 非水平且字形旋转 90°）→ 该块 `unsupported_script` 降级，保留原位原文、不翻译写入，并在报告标注。
- **RTL / bidi（阿拉伯语、希伯来语等）**：V1 不实现双向算法；检测到 RTL 字符占比 > 30% → `unsupported_script` 降级。
- **纯矢量页 / 无文本块**：0 个文本块 → `no_text_block` 降级，译文序列补空白页（见 §7），不报错、不静默跳过。

**对应审查**：墨菲 #4、#6、#8；对抗性 #2（阅读序）。

## 3. 翻译分块（token 预算 + 重叠 + 译后重组）

**分块按 token 预算，不按页。** 一页可含多块，一块可跨页？——V1 **不做跨页段落**：跨页段落按页边界断开，各自成块，断点记入上下文。

### 3.1 预算参数

| 参数 | 默认 | 取值范围 | 说明 |
|---|---|---|---|
| 单次请求目标 token | 1200 | 600–2000 | 触发切块的软上限 |
| 单次请求硬上限 token | 3000 | 固定 | 超过一律切分，防止上下文溢出 |
| 上下文重叠 | 1 段 | 0–1 段 | 仅作为**上下文提示**随请求发送，**不要求模型重译** |
| 超长段落上限 | 3000 token | 固定 | 单段超过则按句切分 |

**token 估算规则**（不引入分词器依赖）：`est = cjk_chars + ceil(latin_chars / 4)`。CJK 记 1 token/字，拉丁约 4 字符/token。估算值用于切块，实际用量以服务商返回为准。

### 3.2 切块规则

1. 按阅读序取段落，逐个累加 `est`；累计至 > 目标 1200 前停止；若加入该段将超过**硬上限 3000**，则在加入前切块。
2. 单段 > 3000 token：按句子边界（`. ! ? 。！？；;` 及其后空白）切分，切到 ≤ 3000；仍无法切分的极端长串按 3000 token 强制切分并标 `segment_split` 降级。
3. 每个 chunk 记录 `chunk_id → [{block_id, span_range}]` 映射，保证译文可逐块回填。
4. 相邻 chunk 发送**上一段原文**作为上下文（`overlap=1`），并在 prompt 中显式标注「以下仅为上下文，不要翻译；只翻译标记段落」。`overlap` 不计入需要回填的输出。

### 3.3 译后重组

1. 模型按 chunk 返回译文；要求返回**逐段结构**（段落序号 + 译文），见 §安全边界的 schema 校验。
2. **疑似未译/回 echo 检测**：对每段译文与对应原文做相似度比对（完全相同或编辑距离归一化 > 95%），或检测模型返回元描述/解释性语句（非译文内容）→ 标记 `untranslated_echo`，该段不回填，触发逐段重译（限 1 次）；仍失败则保留原文并标 `untranslated_echo` 降级。
3. 段落数一致 → 按序号回填。
4. 段落数不一致 → 触发**逐段重译**（该 chunk 降级为逐段请求）；仍不一致 → 该 chunk 记 `reassembly_mismatch` 降级，保留原文并标注。
5. 禁止把整段译文按比例硬切给多个块（会错位）。宁可降级。

**对应审查**：墨菲 #7、#18；对抗性 #2（token 预算）。

## 4. 溢出策略（核心）

原文块框是排版基准；译文长度通常与原文不同（EN→ZH 约缩 40–60%，ZH→EN 约扩 2–3 倍；同字号 CJK 比拉丁宽）。V1 **不采用上游的 BabelDOC 精确排版**，因此必须定义确定性的溢出策略，而非「尽力」。

### 4.1 决策表（按顺序执行，命中即停）

| 步骤 | 条件 | 动作 | 记录 |
|---|---|---|---|
| S0 | 原文块框内、字号 = 原文字号（scale 1.00）可容纳 | 直接排入 | 无 |
| S1 | S0 放不下 | **字体自适应缩小**：scale 从 1.00 起，每步 −0.05，试到最小 **0.70** | 若 scale < 1.00 → `font_shrink`（信息级） |
| S2 | scale=0.70 仍放不下 | **溢出到页边留白**：优先向下扩展（至下一块的 y0 或页底留白），不足再向右扩展（至页右留白） | `overflow_margin` |
| S3 | 扩展后仍放不下 | **裁切**：在块框 ∪ 扩展区 与 相邻块占据区之间取交集，超出部分裁掉 | `clip` |
| — | 步骤 S2 扩展区与相邻块已占矩形相交 | 在相交边界处停住（不得压字），剩余走 S3 | `clip` |
| — | 页面无可用留白（满页） | 直接 S3 裁切 | `clip` |

**执行顺序不可跳级**：不得为了省事直接裁切，必须依次尝试缩小、扩展。

### 4.2 微调参数

- **字号缩放**：仅缩小，不放大（避免译文比原文突兀地大）。步进 0.05，区间 `[0.70, 1.00]`。
- **行高**：先保持原行高；S1 中若缩小字号后仍紧张，行高可从 `source × 1.0` 压到 `source × 0.92`（下限），不再低。
- **字距**：仅 CJK 段落允许负字距，`letter-spacing ≥ -0.01em`（下限），不得用负字距掩盖溢出。
- **单行检测**：缩小后若某行仍超出宽度且该行无断行机会（如长 URL/公式串），不无限缩字，直接进入 S2。

### 4.3 落点与留白

- 溢出方向：**先下后右**。下扩最多到「下一块 y0 − 4pt」或「页底留白边界（CropBox 底 − 24pt）」；右扩最多到「页右留白（CropBox 右 − 24pt）」。
- 不跨页、不自动扩页；需要跨页的内容在 V1 一律裁切并标 `clip`。
- 留白区若本身是图像/矢量图覆盖区 → 不视为留白，不得压图（图像区作为 `blocked` 矩形参与相交判定）。

### 4.4 何时视为「公式 / 表格失败」

- 检测到块内含大量数学字形（私有区 PUA 或 `(cid:NNN)`）或表格线（矢量线段网格）时，标记为 `formula` / `table` 候选。
- 公式块：V1 尝试按普通文本回填；若缩放至 0.70 仍溢出或抽取本身为乱码 → `formula_fail` 降级（保留原文，不写入错误译文）。
- 表格块：V1 按**行内文本**回填，保留行列结构尽力；跨行合并/嵌套/无框线无法还原 → `table_fail` 降级。

**对应审查**：墨菲 #17（核心）、#19；对抗性 #2（回填难度）。

## 5. 字体策略

### 5.1 选字优先级

1. 系统已安装字体，按目标语言选择可再分发的开源字体优先（OFL/Apache 许可，如 Noto / Source Han 系列若本机存在）。
2. 源码文档可复用的字体（仅当目标字形覆盖完整且许可允许嵌入时）。
3. **不下载字体**（受 AGENTS 硬约束）。本机无合适字体时的降级路径：`font_fallback` → 若仍缺字形则 `glyph_missing`。

### 5.2 缺字形（missing glyph）处理

1. 回填前对译文做**字形覆盖检查**：逐字符在候选字体的 cmap 中查覆盖。
2. 覆盖缺失：切换下一个候选字体；全部候选都不覆盖该字符 → 该字符渲染为可见占位（如 `▯`）并标 `glyph_missing`。
3. 不允许静默 tofu：`glyph_missing` 必须进入 §9 降级报告，并在 F4 汇总提示。

### 5.3 嵌入与许可

- 只嵌入**允许嵌入**的字体：检查 `OS/2 fsType` 嵌入位；`Restricted License`（位 `0x0002` 置位）**禁止嵌入**。
- 优先可再分发的字体；**不嵌入受限字体**（如某些厂商随系统分发但禁止再分发的字库）。若唯一可选字体受限 → 改用开源替代；无替代则 `glyph_missing` 降级并建议用户调整语言对。
- 嵌入时**子集化**，仅嵌入用到的字形，减小产物体积。

### 5.4 ToUnicode 与可搜索（硬需求）

- 写入 PDF 的每一段译文必须使用**带 ToUnicode CMap** 的字体或等效「真实文本绘制」方式，保证 `get_text()` 能提取、Ctrl+F 能搜索、复制得到正确 Unicode。
- 若某候选字体无法生成 ToUnicode → **不得使用该字体**；退回可用候选；无候选 → `search_verify_fail` 降级（并说明该页不可搜索）。
- 禁止把译文转成轮廓/图片充当「文本」（会破坏可搜索）。

**对应审查**：墨菲 #21（字体/ToUnicode/#50 可搜索）；对抗性 #2（字体许可）。

## 6. z-order 与原文处理（真实移除，不得用黑框充当删除）

### 6.1 z-order（自底向上）

1. 页面原有**图像 / 矢量图**（保留，不参与重排）。
2. 背景修补层（仅当移除原文后露出底色与周围不一致时铺同色；颜色取自块外缘邻近像素/底色，不得用黑框）。
3. 译文文本层。
4. 降级标记（如需要，见 §9）。

译文层在图像之上、并覆盖原文本层区域。

### 6.2 原文真实移除

- 回填某块前，先用 **区域真实移除**（PyMuPDF redaction：对该块矩形加 redaction 注释并 `apply_redactions`，**保留图像**）删掉原文本字形；不得仅用不透明矩形遮盖了事——遮盖下原文仍可被搜索/复制，违反「输出可搜索且不含原文」。
- **禁止用黑框代表删除**（沿用 AGENTS「不能把黑色覆盖图形当作永久删除」原则）。背景修补必须匹配底色，且只用于视觉修补，不承担「删除」语义。
- 移除矩形按原文块框（见 §1 归一化坐标）；若块与图像重叠，redaction 需设置保留图像选项，不得连带删除图像内容。
- 移除后立即写入译文；两件事在同一个页面处理批次内完成，避免中间态产物。

### 6.3 不可移除的情形

- 扫描件原文是**光栅图像的一部分**（pixel 烧入），无法用文本 redaction 移除。此时 mono/dual 的「译页」为原图之上叠加译文文本（原图仍在），标 `raster_overlay` 降级——即扫描页无法做到「原文被移除」，必须在报告与 F4 明示，避免用户误以为原文已替换。

**对应审查**：墨菲 #19、#22；对抗性 #5（替换标注/源只读）。

## 7. 双页对照（dual）对齐不变量

**不变量**：`译文序列第 N 页 ↔ 原文第 N 页`。

1. V1 **不因溢出而扩页**（溢出走裁切降级），因此 mono 页数 = 原文页数。
2. **跳过页补空白**：整篇可选「跳过扫描页 / 无文本块页」；被跳过的页在译文序列中**插入等量空白页**，保持 N↔N，并标 `skip_page`。
3. **失败页**：某页翻译失败但用户选择继续 → 该页写回原文或空白并标 `page_failed`，不改变页数与顺序。
4. **默认排布**：「译页紧跟原页」（原 1, 译 1, 原 2, 译 2, …），**不自动左右并列**。
5. **左右并列**仅在用户显式选择时启用，且要求：页面为横向、左右两页均能容纳不缩至 < 0.7；否则回退为上下（紧跟）排布并提示。
6. OCR 导致的页合并/拆分：V1 不做页合并；OCR 结果仍按原页码归位，跨页文本按 §3 页边界断开。

**对应审查**：墨菲 #20；对抗性 #5（dual 对齐）。

## 8. 可搜索输出（硬需求）

**要求**：mono 与 dual PDF 的译文部分必须可提取文本（真实文本 + ToUnicode），可搜索、可复制。

**导出后校验（F4 增加步骤）**：

1. 对输出 PDF 逐页 `get_text()`，抽取译文文本。
2. **存在性校验**：译入语内容可被提取（与回填文本做规范化后比对，容忍空格/连字差异）。
3. **原文缺失校验**：对每个被替换块，原地不应再提取到原文（防止残留导致「搜到原文」）。
4. **覆盖率**：可提取文本页数 / 应有译文页数；低于阈值（默认 95%）→ 页面标 `search_verify_fail`。**注意**：此 95% 为运行时每页阈值，仅标记/降级单页；V1.1a spike 退出标准要求 100% 覆盖率（见《需求总结.md》V1.1a），二者有意不同。
5. 扫描/光栅叠加页天然不可搜索 → 计入报告「不可搜索页」，不算失败，但必须在 F4 明示。

**对应审查**：墨菲 #21、#50。

## 9. 每页降级标记与报告

### 9.1 降级原因枚举（per-page）

| 标记 | 触发 | 用户可见文案（示例） |
|---|---|---|
| `font_shrink` | 字号被缩小（S1） | 该页为适配译文缩小了字号 |
| `overflow_margin` | 溢出到页边留白（S2） | 该页译文超出原文块范围 |
| `clip` | 被裁切（S3） | 该页存在被裁切的译文 |
| `font_fallback` | 字体被替换 | 该页使用了替代字体 |
| `glyph_missing` | 目标字形缺失 | 该页存在无法显示的字符 |
| `formula_fail` | 公式回填失败 | 该页公式未保留原样 |
| `table_fail` | 表格结构无法还原 | 该页表格结构可能丢失 |
| `reassembly_mismatch` | 译文段落与原文对不齐 | 该页部分内容未回填 |
| `extraction_low_conf` | 抽取置信度低（乱码/PUA） | 该页原文抽取可能不可靠 |
| `rotation_crop` | 旋转/裁剪页回填受限 | 该页因旋转/裁剪回填降级 |
| `unsupported_script` | 竖排/RTL 不支持 | 该页文字方向不支持，保留原文 |
| `no_text_block` | 无文本块 | 该页无可用文本（纯图/矢量） |
| `skip_page` | 用户跳过 | 该页未翻译 |
| `page_failed` | 该页失败继续 | 该页翻译失败 |
| `raster_overlay` | 扫描页原文不可移除 | 该页原文为图像，未移除 |
| `segment_split` | 超长段落被切分 | 该页有超长段落被切分 |
| `search_verify_fail` | 导出后校验未过 | 该页译文可能不可搜索 |
| `untranslated_echo` | 译文与原文相同/高度相似或返回非译文内容 | 该段疑似未翻译/回显 |

### 9.2 报告 schema（概念）

```
{
  "task_id": "...",
  "pages": [
    { "page": 3, "degraded": true, "reasons": ["font_shrink","table_fail"], "searchable": true },
    { "page": 7, "degraded": true, "reasons": ["raster_overlay","search_verify_fail"], "searchable": false }
  ],
  "summary": { "degraded_pages": 2, "unsearchable_pages": 1, "total_pages": 12 }
}
```

- 报告与产物同目录保存（如 `译本-降级报告.json`），并写入 F4「每页降级报告」入口。
- F4 顶部显示聚合：`降级页 n/total · 不可搜索页 m`。
- 报告仅含页码与原因，**不含文档正文、密钥**。

### 9.3 标记在产物中的呈现

- **统一规则**：「机器翻译 · 请核对」标记**同时出现在结果区（F4/F6b）和产物 PDF 中**，但**不在译文正文上加水印**。
- **结果区**：F4 完成态常驻显示标记（不因「成功」样式被淡化）；F6b 批量结果列表同样标注。
- **产物 PDF**：每页**页脚加极小标记**（默认**开启**，小字号如 6pt、灰色、页脚位置、不遮挡正文内容）。一般文档用户可在设置中关闭该标记；但**法律/医学高风险模板产出的 PDF，页脚标记为强制显示、不可由设置关闭**，以满足合规可见性要求。
- 标记文字固定为 `机器翻译 · 请核对`，不含其他说明；字体用与正文不同的浅灰色以区分，但不使用醒目颜色以免干扰阅读。

**对应审查**：墨菲 #44、#45；对抗性 #7（诚实）。
