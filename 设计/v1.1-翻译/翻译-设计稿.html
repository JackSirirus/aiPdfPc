规格说明 · F1

状态与行为
  • 选中即显「译」浮钮；点击后卡片先出骨架，返回后替换为译文。

  • 引擎：默认 本地（需自备运行时）；云端须主动选择并先同意（见 F5）。

  • 无文本层页：划词入口禁用，引导整篇（先 OCR）/ 本页 OCR。

  • 选「法律 / 医学」模板 → 先弹高风险确认（见 F2b），确认后才可开始。
  • 模板「自定义」展开文本框；术语表可现场编辑，保存后复用于批量。
字段与默认值
  • 源语言：自动检测（可显式指定，如英/日）。
  • 目标语言：中文（显式选择，不自动检测）。

  • 输出：mono ✓ + dual ✓；Markdown 默认关。

规格说明 · F3

状态与行为
  • 阶段固定：抽取 → OCR（如需要）→ 翻译 → 回填 → 导出；当前阶段高亮。
  • 日志只显示诊断行，不含文档正文与密钥。

  • 「后台继续」收起右栏任务视图，状态栏保留迷你进度与取消入口；仅本次会话内有效。

字段与默认值

  • 重试：同一错误最多 2 次（共 3 次尝试），指数退避；拒译/取消不重试。
  • 任务通道：复用全局任务队列，串行，可取消。
  • 状态栏迷你进度默认开启。

规格说明 · F4

状态与行为
  • 完成即生成两个结果行；点「打开」在新标签打开对应 PDF。
  • 结果区常驻 「机器翻译 · 请核对」 标记，不因「成功」样式被淡化；产物 PDF 每页页脚同样加极小标记（一般文档默认开启、可在设置中关闭；法律/医学高风险模板强制显示、不可关闭）。
  • 可搜索校验：导出后逐页校验译文可提取；异常页标注并计入「每页降级报告」。
  • 每页降级报告入口：显示降级页数、原因（表格/公式/裁切/缺字形/扫描叠加等）与不可搜索页。
  • 聚合上传披露：使用云端时明示「全文文本已分批发送」，不写「仅片段」。
  • Markdown 导出为可选附加产物，失败不影响 PDF 结果。
  • 「再译一次」回到配置态并保留上次设置。
字段与默认值
  • 产物命名：原名-纯译文.pdf / 原名-对照.pdf；同名冲突加序号。
  • 输出目录：每次新建 `AIPDF-日期-编号-翻译`，不覆盖源文件；默认根为用户文档目录。
  • dual 对齐不变量：原文页 N ↔ 译文页 N；跳过/失败页补空白页；默认译页紧跟原页，不自动左右。
  • 降级报告：译本-降级报告.json（仅页码与原因，不含正文/密钥）。
  • 可搜索：译文必须为真实文本 + ToUnicode；扫描叠加页天然不可搜索，需明示。
  • Markdown：默认不生成，勾选后才产出 原名.md。

规格说明 · F5

状态与行为
  • 仅在该 provider + endpoint 组合首次使用云端（且未记住）时弹出；同意后进入任务。
  • 「记住我的选择」按 provider + endpoint 记忆；端点主机名/协议/端口任一变更 / 切换服务商 / 更换密钥 → 重新弹出；仅改模型名（端点和密钥不变）不重置。
  • 未勾选「记住」→ 每个组合每次会话首次使用仍提示一次，但不要求重填 key。
  • 同意记录带 TTL；过期自动重新提示。
  • 「改用本地引擎」关闭模态并把引擎切为本地（无运行时则提示去配置）。
  • 「取消」不发起任何网络请求，回到配置态。
  • 拒绝记忆或拒绝同意 → 回退本地或停用云端入口（见全状态稿）。

  • 首项勾选：默认未勾选，须用户主动勾选才能继续；第二项也默认不勾。
