# AIPDF Windows 阅读器 × 主流 PDF 阅读器：功能与 UI 对比

> 日期：2026-10-11
> 目的：回答「本项目像不像一个 PDF 阅读器」之后的下一个问题——**和主流阅读器比，功能差在哪、UI 差在哪**，并给出该补 / 不该补的判断。
> 对比对象（6 家）：Adobe Acrobat Reader、Microsoft Edge 内置 PDF 阅读器、SumatraPDF、PDF-XChange Editor、福昕 Foxit（Reader/Editor）、WPS PDF。
> 方法：本项目一侧以**仓库代码与文档为准**（`catalog.json`、PRD、验收记录、实际 XAML/CS）；竞品一侧由**三路独立调研**产出，每条关键事实附一手来源 URL；未读到原文的标「未能核实」，不臆测。
> 局限：竞品官方手册常落后于产品（PDF-XChange 手册只有 V10 而产品已 11.1；Foxit Windows HTML 手册 500 而 Mac 版正常）；Adobe helpx 有反抓取；WPS 隐私政策页是 SPA 抓不到正文。详见第 7 节。

### 1.4 其它已核实的本方事实

- **界面语言**：仅简体中文（无多语言资源文件）。
- **触控/手写笔**：无专门触控模式；手写批注走 Ink，输入以鼠标/笔事件为主。
- **无障碍**：WPF 默认 UIA 树 + 49 处 `AutomationProperties`；**无 PDF/UA 检查器、无屏幕阅读器专项**。
- **工具栏自定义**：无。
- **搜索范围**：仅当前文档。

### 3.1 UI 层面三个结论

1. **「阅读操作放哪」主流并不统一**：Edge/Acrobat 放顶部工具栏，PDF-XChange/Foxit/WPS 放底部状态栏，SumatraPDF 两边都有。→ **方案 A 把页码/缩放并入底部状态栏，是主流做法之一，不是异类。**
2. **导航面板左侧仍是主流**：SumatraPDF/PDF-XChange/Foxit/WPS 都在左侧，只有新版 Acrobat 放右侧（其官方文档还自相矛盾）。→ 我们左栏四面板站得住。
3. **我们真正缺的是「入口收敛」与「可定制」**：Acrobat 用三级视图、PDF-XChange/Foxit/WPS 用 Ribbon、SumatraPDF 用命令面板；我们四个入口并列且都不可自定义。**最值得抄的是命令面板（SumatraPDF `Ctrl+K` / Foxit `Alt+Q`）**——一个入口同时装下命令、历史、标签、缩略图、目录、批注、设置。

## 5 结论

1. **功能**：本项目「阅读」中等偏上、「批注」偏弱（缺下划线/删除线/波浪线/图章/回复/汇总，无属性面板）、「朗读与演示」缺失、「数字签名」缺失；但**赢在工具链（33 个免费本地工具）+ 整篇翻译（免费本地）+ 无遥测无广告**——这个组合 6 家竞品都没有。
2. **UI**：主框架（顶栏 + 左面板 + 底栏）与主流一致，方案 A 之后已不是「转换器外观」；真正缺的是**入口收敛（命令面板）**、**可定制（快捷键/工具栏）**、**沉浸阅读**。
3. **最该做的四件事**：① 补 `Ctrl+B`；② 批注补下划线/删除线/图章；③ 做 `Ctrl+K` 命令面板；④ 补朗读 TTS 与全屏/演示。
4. **对外表述要修正一处**：我们的「PDF 签名」是手写/图片签名，**不能称「电子签名」**（WPS 官方都自认这类签名无加密认证）；要称「手写签名」，数字证书签名是独立缺口。
5. **明确不做**：付费水印、额度漏斗、广告、登录漏斗、默认遥测、云端 AI、Ribbon 化。

## 7 未核实与局限

**方法局限**
- Adobe helpx 有反抓取，部分页面只能经「针对该官方 URL 的搜索索引」抽取正文。
- **PDF-XChange 官方在线手册只有 V10**（`pdfxe11` 404），产品已 11.1.0.0。
- **Foxit Windows HTML 手册返回 HTTP 500**，Windows 界面分区名取自官方手册 PDF 经搜索索引的原文摘录；Windows 默认快捷键只核实到 3 条（Ctrl+S / Ctrl+Shift+T / Alt+Q），完整表是 Mac 版。
- **WPS 隐私政策页是 SPA**，抓到的正文为 1 字节 → 「用户体验改善计划是否默认开启、能否关闭、是否上传文档」完全未取得官方原文；只能确认移动版 EULA 明文允许广告。
- SumatraPDF 稳定版 3.6.1，大量文档条目描述 **3.7 预发布**功能（朗读、数字签名、脱敏、缩略图侧栏、Merge 窗口）。

**关键未核实项**
1. **SumatraPDF / PDF-XChange / Foxit / WPS 的加密 PDF 保存批注后是否仍加密**（我们的关键差异点，各家均未核实）。

4. Foxit 免费 Reader 是否强制登录；安装向导之外是否还有遥测开关；是否默认上传文档。
5. SumatraPDF 是否支持批注回复线程、FDF/XFDF 导出、认证签名（certify）、CJK 搜索质量。
