S11边界

缩放边界（25% / 400%）

Ctrl+滚轮 / 按钮 到达阶梯端点。
25%
  • 阶梯：25 / 33 / 50 / 67 / 100 / 150 / 200 / 300 / 400%。到边界后按钮置灰禁用，Ctrl+滚轮不再变化。
