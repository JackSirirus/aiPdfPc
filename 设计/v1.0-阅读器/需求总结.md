## 背景

AIPDF 目前是一个"工具优先"的工作台：打开应用先选工具，再拖文件、调参数、处理。文档只是工具的输入，阅读场景完全缺位——没有连续滚动阅读、目录、书签、全文搜索和批注。日常"打开一份 PDF 看看"的最小诉求都必须先经过工具选择流程，本末倒置。

用户意图：**把应用从 PDF 工作台变成 PDF 阅读器，但 32 个工具一个不丢**。本质是信息架构倒转：从"工具为中心"变为"文档为中心"，工具降级为文档上下文中的操作。

## 目标

1. 打开 PDF 即进入沉浸阅读：连续滚动、缩略图/目录/书签、全文搜索。
2. 32 个工具无损保留，以文档上下文方式进入（四通道：右抽屉 / 模态向导 / 选中浮菜单 / 临时标签；无文档场景走起始页工具网格）。
3. 批注（高亮 + 笔记）就地写回原 PDF（引擎原子保存），防抖自动保存走独立快速通道。
4. 阅读状态跨会话记忆（页码、缩放、侧栏、书签）+ 会话恢复（标签集合、窗口状态、左栏宽度）。
5. 处理结果即文档：输出 PDF 自动开新标签进入阅读流。
6. 支持打印当前文档；注册"用 AIPDF 打开"文件关联（单实例）。

## 功能范围

### 做什么

- **基础阅读包**：连续滚动、缩略图、目录（PDF 大纲）、书签（用户自建）、页码跳转、缩放阶梯（25/33/50/67/100/150/200/300/400%）、适配宽度/页面。
- **多标签页**：一窗多文档；顶栏 = 品牌 + 标签 + ＋ + 全文搜索 + 设置。
- **全文搜索**：Ctrl+F，左栏第四面板命中列表 + 页内高亮，回车/Esc 导航（Esc/✕ 退出并恢复原面板）；无文本层文档禁用并引导 OCR。
- **选中浮菜单**：复制 / 高亮 / 笔记 / 用工具处理▾（子菜单：压缩/拆分/旋转/转 Word + 更多工具…，页码预填当前页）。
- **批注持久化**：高亮 + 文字笔记；2 秒防抖（最后一次批注操作后计时）；**就地写回原文件**（引擎原子保存：临时文件→os.replace→fsync；加密文档保留加密）；状态栏三态（保存中/已保存/失败重试）；保存走**独立快速通道**，30s 无响应转失败。
- **阅读状态记忆**：页码/缩放/侧栏/书签，键 = 路径 + size/mtime 校验，存于 `%APPDATA%\AIPDF\reading-state\`；孤儿 GC（90 天/上限 100 条）。
- **会话恢复**：退出时持久化标签集合、窗口尺寸/位置/最大化态、左栏宽度与面板选择；启动时恢复。
- **打印**：当前文档打印（基于渲染栈的分页位图输出到 WPF 打印管线）。
- **文件关联**：注册"用 AIPDF 打开"（.pdf）；**必须配单实例互斥**（二次启动唤起已有实例开新标签）；安装脚本注册、卸载清理。
- **起始页**（无文档时的唯一主界面）：打开按钮 + 最近文件卡片（含进度元信息）+ 常用工具网格（v1.0 静态清单）+ 全部 32 工具入口。
- **工具进入四通道**：右抽屉（单文件工具内联参数面板，已确认）、模态向导（多文件/多步工具）、选中浮菜单、临时标签（复杂编辑工具复用现有工具页，每标签页面实例缓存）。无 PDF 输入的工具（扫描为 PDF、图片转 PDF）只走起始页；32 工具 → 通道完整映射表 = **PRD 首个交付物**（判据已定）。

### 不做什么

- 双页对开、夜间阅读模式（后续版本候选）。
- macOS 端同步重构（Windows 优先，SwiftUI 后延）。
- AI 摘要/翻译、模型连接、模型下载（维护者明确排除，沿袭）。
- 手写/形状批注工具栏（v1.0 批注仅高亮 + 文字笔记）。
- 云同步、协作批注、证书数字签名（沿袭现有边界）。
- 自动生成目录、目录编辑（仅读取文档自带大纲）。
- 拖入文件夹批量打开（仅 PDF 文件）。
- 检查更新（已裁决：v1.0 排除，⚙ 菜单移除；有分发渠道后重新评估）。

## 载体

Windows WPF 主窗口重构（`Sources/AIPDF.Windows`）。阅读器为**唯一主界面**：

- `MainWindow` 的 `ToolPageHost`（ContentControl）位改造为标签页宿主（TabControl 方向）。
- 无文档时整个主区显示起始页。
- 工具参数 UI 两种形态：右抽屉内联参数面板（单文件工具）、居中模态向导（多文件/多步工具）；复杂编辑工具（编辑/表单/裁剪）以临时标签承载。

## 技术约束

技术调研（2026-09-10，两个并行 explore agent）+ 对抗性审查（三路）核实与修订：

- **渲染管线必须重建（含裁决后的选型方向）**：现状 `PdfPreviewDocument`（PDFtoImage 5.4.0）无状态逐页调用——每次渲染重解析整个 PDF（`GetPageSize` 一次 = 一次全量解析；一次渲染 = 2 次全量解析）、同步阻塞 UI 线程、无缓存、整文件读入内存（打开瞬时峰值 2× 文件大小）。裁决：**替换为持久句柄 PDFium 绑定**，需：持久文档句柄 + 页尺寸一次解析全局缓存 + 后台线程渲染 + 页面 LRU 缓存（**按字节预算，建议 ≤256MB**）+ 虚拟化容器 + **PDFium 全局单锁**（非线程安全，并发调用 = 原生崩溃）+ 超纹理尺寸分块渲染或缩放限幅（400%×150%DPI = 5052px 超 4096px 纹理上限）。
- **文本层与渲染同栈**：持久句柄绑定需暴露 FPDFText_*（文本提取/命中测试/矩形）。坐标复用 `PdfCoordinateMapper`（可见旋转页、左上原点、pt——与 engine.py area() 一致，无需换算，已核实）。
- **批注保存链路（裁决后）**：客户端叠加渲染（复用 region-selection Canvas）→ 2s 防抖 → **独立快速通道** EngineBridge 请求 → **引擎新增注释操作**（就地原子写回：临时文件→os.replace→fsync；加密文档传 password 并保留加密——引擎 save_pdf 现强制 PDF_ENCRYPT_NONE，需新增加密保存参数）→ 成功后叠加层清除对应批注（以 PDF 注释为唯一真相源，防 WithAnnotations=true 双重渲染）→ 重载保留视口。保存前 size/mtime 冲突检测，冲突弹对话框。30s 超时转失败。
- **引擎桥接契约**：一进程一请求（stdin 单行 JSON、stdout 单行 JSON、stderr 进度），取消 = taskkill 子进程树，无内部超时（批注保存的 30s 由 WPF 侧计时）。密码逐请求经 `options.password`；**会话密码驻留为 net-new**（标签内存会话，解锁一次后续免密；密码绝不进入阅读状态/最近列表/会话恢复持久化）。关键事实：redact 删除全部既有批注（UI 需明示警告）；编辑类操作对旋转页 remove_rotation（输出页 /Rotate 归零）；compress 无收益时复制源文件（Toast 说明而非开新标签）；pure PyMuPDF 操作无内部超时。
- **持久化模式**：所有新存储（reading-state/、session.json）沿袭 `WorkflowPresetStore`（schema 版本、UTF-8 no-BOM、文件名消毒、密码剔除）。
- **标签宿主**：`ToolPageHost` 位改造；**每标签页面实例必须缓存**（registry 现状每次重建会丢临时标签的工具状态）；文档上下文传文件需 registry 重载/交接服务 + `AddFiles([path])`（API 已存在）。
- **应用无设置 UI（核实）**：⚙ 菜单三项全部 net-new；"检查更新"已裁决排除并从设计稿移除；设置面板与"关于·许可"页为 PRD 范围（设置存储沿袭持久化模式）。
- **单实例互斥（文件关联连带，必须项）**：启动检测已有实例 → 唤起并传文件路径开新标签。
- **重用清单**：`PdfCoordinateMapper`、缩放阶梯 + Ctrl+滚轮、region-selection 叠加、`EngineBridge`、`AddFiles` 通道。
- **新建清单**：持久句柄渲染服务（页尺寸缓存+全局锁+字节预算 LRU）、文本层、搜索、批注模型+原子保存流、标签宿主、起始页、向导骨架、任务队列、会话密码驻留、设置面板、会话恢复、打印管线、文件关联+单实例。
