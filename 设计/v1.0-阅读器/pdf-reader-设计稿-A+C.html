七、Token 对照（亮 / 暗）
左边为 A+C 提议值，右边为暖暗色对应值。所有既有键名不变；标「新增」者当前无对应 token，需新增且亮暗成对。
下表颜色随右上角主题切换实时变化；色值文本为当前主题实际值。
字体：UI / 正文 = Segoe UI Variable Text / Microsoft YaHei UI / system-ui；展示标题（hero、页标题、区块标题、面板标题、模态标题）= 衬线回退链 "Source Han Serif SC","Noto Serif SC","Songti SC","SimSun",Georgia,serif。 不内嵌字体，WPF 用系统字体 + 优雅回退。
动效：120–160ms ease-out（本稿 --dur:140ms）——标签/导航 hover、保存胶囊状态 morph、锁定遮罩 fade、卡片 hover 抬升；尊重 prefers-reduced-motion。
本文件为纯设计产物，未改动 Sources/、tests/ 或验收记录。实现映射、分阶段计划与新增 token 清单见同目录《A+C-设计说明与token清单.md》。 纸纹为纯 CSS 内联 SVG 噪点，仅作用于阅读画布背景层，不进入页面位图，打印/导出友好；WPF 侧建议用极低不透明度 DrawingBrush 近似或直接省略。
