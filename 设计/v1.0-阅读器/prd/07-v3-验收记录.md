## 2. 预算实测（按影响面，裁决 Q13）

**P95 口径**：对 n 个 `Stopwatch` 样本升序排序后取第 `ceil(0.95*n)-1` 个（0 基）。

### 2.1 B1 / B2 / B5：不适用（V3 未改动该路径）

裁决 Q13：**单栈不改阅读器 B1/B2**；仅当 `PdfiumRenderService` 渲染路径被改动时才复测。T2 对 `Rendering/PdfiumRenderService.cs` 的改动经逐行核对为：

- **新增**（纯增量，阅读器不调用）：`OpenDocumentSharedRead` / `OpenDocumentFromBytes`（预览专用打开语义）、`EnableFormFill` / `RenderPageWithFormFillAsync`（预览表单 Widget，Q5）、`RegisterDocument` 抽取。
- **删除/改写**：仅 `OpenDocument` 内部取注册键的重复代码合并为 `TryGetRegistered` + `RegisterDocument`（打开路径重构，**不在 B1/B2 的「热文档已打开」测量边界内**）。
- **`RenderPageAsync(docId,page,dpi,zoomPct)` 与 `RenderPageCore(...)` 主体零改动**（V3 范围内 `-` 行全部落在 `OpenDocument` 重构区，逐行核对见证据 `v3-task12-budget.txt`）。阅读器屏上仍走 `ScreenRenderFlags`（BLK-5），逐字节不变。

因此 **B1（96dpi）/ B2（150dpi）/ B5（搜索）本轮不重复测量**（非「测不出」，而是按 Q13 影响面判定为「不适用」）。参考基线（V2 实测，`06-v2-验收记录.md` §2.2）：B1 7.15 ms、B2 9.19 ms、B5 47.76 ms，均远低于 200 ms / 200 ms / 500 ms。

> 说明：本任务约束「不得改产品/测试代码」，故不新建一次性性能 harness（V1/V2 的临时 xunit harness 已删除）。若维护者要求 V3 结束时复测 B1/B2/B5，可用与 V1/V2 相同的一次性 harness 方式另开授权执行。

### 2.2 B6：不适用（未被 V3 影响）

指标 6「缩略图生成吞吐 ≥ 20 页/秒」。C1 双页对开只改阅读布局分组与虚拟化（`PageGroupMap` / `PageLayoutCalculator`），C2 主题只改资源字典，C3 手写/形状只改批注模型与工具栏——**均不改缩略图生成路径**（仍为 `RenderPageAsync` 小尺寸调用）。故按 Q13「仅在 C1/C2/C3 影响启动/缩略图/流式渲染时首次实测」，B6 不在 V3 影响面内，未测。

### 2.3 B10：首次实测（C2 主题 + SettingsStore 命中启动路径 → 影响面适用）

指标 10「应用冷启动→可交互 < 2 s」。C2 主题在启动时读取 `%APPDATA%\AIPDF\settings.json`（`SettingsStore`）并应用主题资源字典，故属影响面，进行**首次实测**。

- **代理口径**：`Start-Process dist\aipdf-windows\app\AIPDF.Windows.exe` → 轮询 `Process.MainWindowHandle != 0`（主窗口句柄出现）；每次启动后 `Stop-Process` 再等 0.5 s，共 15 次。启动前进程未运行，无文档加载（符合预算定义）。
- **脚本**：`tmp/v3-b10-coldstart.ps1`（合成一次性脚本，`tmp/` 不入库，不修改产品/测试代码）。

| 轮次 | 样本（ms，15 次） | P95 | 判定 |
|---|---|---|---|
| 第 1 轮（紧随一次全新 `build.ps1` 之后） | 5492.6, 813.5, 714.6, 839.1, 830.8, 734.1, 756.9, 757.2, 714.8, 719.9, 716.9, 734.5, 769.5, 798.9, 837.8 | **5492.6**（=max，被首启拉高） | 首启一次性成本 |
| 第 2 轮（文件已被 OS 缓存） | 874.2, 718.5, 936.2, 840.7, 748, 764.2, 840.1, 715.5, 1050.7, 750.6, 716.6, 797.2, 749.6, 862.3, 717.8 | **1050.7**（min 715.5 / median 764.2 / max 1050.7） | **PASS**（-47%） |

- **判定**：稳态冷启动 P95 **1050.7 ms < 2000 ms → PASS**。第 1 轮 iteration 1 的 5492.6 ms 是换新二进制后 OS 文件缓存为空 + 安全软件首次扫描导致的一次性成本，第 2 轮同机同构建已消失（首启 874.2 ms）。**如实记录**：若严格把「换新构建后的首次启动」也计入冷启动样本，则该单次样本超预算；这不是代码回归（无对应代码路径改动），属环境冷缓存成本。
- 局限：以「主窗口句柄出现」为「可交互」代理，未做像素级「渲染完成」判定；人工点击体验交 F3。
