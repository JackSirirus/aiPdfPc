## 2. 预算实测

**P95 口径**：对 n 个 `Stopwatch` 样本升序排序后取第 `ceil(0.95*n)-1` 个（0 基）。
**B1/B2/B5 语料**：`tmp/t2-corpus/corpus/t2-cjk500.pdf`（500 页中英混合文本层）与 `tmp/pdfium-spike/corpus/text1000.pdf`（1000 页）；均为合成文件，`tmp/` 不入库。
**应用层口径**：经真实服务 API（含后台线程/锁/LRU 等应用层开销）。

### 2.1 B7 批注保存往返（新增）

| 指标 | 定义（本次方法） | 目标 | 实测 | 样本 | 判定 |
|---|---|---|---|---|---|
| **B7** 单条批注保存往返 | 50.35 MB 已打开 PDF（合成 4 页随机噪声图，deflate 无法压缩）；单条 Highlight 走 `AnnotationSaveService.FlushAsync`（**跳过 2 s 防抖**）→ 真实 `EngineBridge` 子进程 → `backend/engine.py` 原子就地写回（temp → 校验 → fsync → `os.replace`）→ 成功回调 | < 2000 ms（中位数） | **中位数 1080.3 ms**（min/median/max = 816.2/1080.3/1339.9；P95 1286.9） | n=20 | **PASS**（-46%） |

- 起止点与计划一致：**排除 2 s 防抖**，仅计「提交引擎 → 收到成功响应」的引擎往返 + 原子写回。
- 语料：`tmp/t12-corpus/b7-50mb.pdf`（50,351,562 B = 48.0 MiB；生成脚本 `tmp/t12-corpus/gen_50mb.py`，合成、不读个人文档）。
- 样本序列（ms）：816.2, 824.3, 840.1, 868.1, 905.3, 918.6, 932.2, 937.2, 941.9, 1065.0, 1080.3, 1144.3, 1144.3, 1159.5, 1160.4, 1180.1, 1183.4, 1240.7, 1286.9, 1339.9。
- 结论：50 MB 全量重写（`garbage=4, deflate=True`）+ 写后校验 + 替换的往返中位数约 1.08 s，达标且余量约 0.9 s。

### 2.2 B1 / B2 / B5 复测（开启 `FPDF_ANNOT` 后）

T1 最终决策（BLK-5，见 `Rendering/PdfiumRenderService.cs`）：**屏上 `ScreenRenderFlags = FPDF_ANNOT`**；`FPDF_PRINTING` 是打印语义（Print 位为假的注释不上屏），仅用于打印路径 `PrintRenderFlags = ANNOT | PRINTING`。故本节复测的是「开启屏上注释渲染」后的真实屏幕路径。

| 指标 | 定义（本次方法） | 目标 | 实测 | 样本 | 判定 |
|---|---|---|---|---|---|
| **B1** 单页渲染 96dpi | 热文档、每次**不同页**（非 LRU 命中）；`RenderPageAsync(page, 96, 100)` | < 200 ms | **P95 7.15 ms**（min/median/max = 1.07/2.20/38.29） | n=30 | **PASS** |
| B1（1000 页语料） | 同 B1，corpus=text1000 | < 200 ms | **P95 2.93 ms** | n=30 | **PASS** |
| **B2** 单页渲染 150dpi | 同 B1，dpi=150 | < 200 ms | **P95 9.19 ms**（min/median/max = 2.73/5.33/12.24） | n=30 | **PASS** |
| B2（1000 页语料） | 同 B2，corpus=text1000 | < 200 ms | **P95 5.51 ms** | n=30 | **PASS** |
| **B5** 全文搜索 | 500 页文档，首次搜索建全量索引后重复搜索同一词（排除首次索引） | < 500 ms | **P95 47.76 ms**（min/median/max = 37.46/40.95/47.82）；首次索引构建 115.0 ms（一次性） | n=30 | **PASS**（-90%） |

- V1 参考值（未开注释渲染）：B1 3.09 / B2 6.99 / B5 69.62 ms。复测仍在同一量级，远低于目标；B1 的 max 38.29 ms 来自首个样本 JIT/预热，P95 不受影响。
- **注释渲染位图耗时差**：对含内嵌注释的合成页（`tmp/t1-annot-corpus`）以 flags=0 与 flags=`FPDF_ANNOT` 各渲染 20 次（每轮先 `ClearDocumentCache` 确保真实渲染，非缓存命中）：

| 语料 | flags=0 中位数 | flags=ANNOT 中位数 | 差值 |
|---|---|---|---|
| annot-freetext（FreeText 笔记） | 1.65 ms | 1.62 ms | −0.03 ms（噪声内） |
| annot-print-false（Print=false 高亮） | 1.72 ms | 2.17 ms | +0.45 ms |

- 结论：屏上开启注释绘制的位图开销约 < 1 ms/页，对 200 ms 预算影响可忽略；`FPDF_PRINTING` 未用于屏幕（BLK-5），故不影响屏上视觉基线。

## 8. 已知问题与环境阻塞（如实记录）

### 8.1 环境阻塞

1. **LibreOffice 环境挂起（既有，非 V2）**：`tests/test_engine.py::test_office_imports_and_pdfa` 因本机探测到的 `D:\Program Files (x86)\program\soffice.exe` 挂起（`--headless --version` 不退出）→ 引擎 300 s 超时后报「本地转换超时」。V1/T3 已记录同一问题；与 V2 代码无关。Office/PDF-A 在有可用 LibreOffice 的机器上可复跑。
2. **Smart App Control 评估态**：本机 SAC=1（`VerifiedAndReputablePolicyState=1`），新构建未签名二进制按哈希/云信誉概率性拦截（`0x800711C7`）。本轮 `dotnet test` 与 `dist` 启动**均未被拦截**；T13 曾遇拦截并改用沙盒。属本机策略，非代码缺陷。
3. **UI 深度点击未全部自动化**：本轮已执行 GUI 抽样（打开文档、工具箱 → merge 临时标签、单实例唤起转发、冷启动带 `.pdf`）。edit 框选拖拽、右抽屉（organize/pdfa）完整交互、逐工具「进入→处理→产出文件」及窗口截图**未在本轮自动化**，交 **F3 真实操作 QA 波次**（与本环境不冲突，GUI 已可用）。

### 8.2 已知限制（V2 范围既定，非缺陷）

1. **同 size/mtime 的外部编辑无法检出**（Q4，无 SHA-256；不声称「不漏报」）。
2. **旋转页（/Rotate）禁用选区/批注**（M-11；`PdfCoordinateMapper` 无 derotation，V2 不新建换算层）。
3. **redact 同时删除全部 Widget 与清空 TOC**（M-12，既有引擎语义；UI 警告文案已说明）。
4. **加密批注就地保存的 owner 密码不保留**：PyMuPDF 1.28.2 `PDF_ENCRYPT_KEEP` 在用户密码会话下会写坏新增注释，改用显式 AES-256 重加密（保留用户密码/算法/权限位，owner 变为新随机值）；非 AES-256 源会升级为 AES-256（已知限制）。
5. **原子替换的属性丢失（L-2）**：temp + `os.replace` 不迁移创建时间/隐藏只读属性/ACL/ADS/硬链接/符号链接（V2 明确不做元数据搬迁）。
6. **屏上渲染仅 `FPDF_ANNOT`**（BLK-5）：`FPDF_PRINTING` 为打印语义，Print 位为假的注释不上屏，故屏幕路径不使用；打印路径预留 `ANNOT | PRINTING`。与 PRD 4.1.3 的打印口径一致，屏幕为视觉回归修正。
7. **双文档句柄未收敛**（渲染服务与文本服务各一份句柄）：V2 不收敛，属 V3。
8. **与 PRD 的既定裁剪**：`AC-23.2`（加密 + compress 仍加密）移出 V2（`save_pdf` 对普通工具强制 `PDF_ENCRYPT_NONE`）；FR-26（hash 惰性比对）移出 V2；向导骨架/设置/打印/单栈收敛/双页/夜间属 V3。
9. **测量波动**：B1/B2 受 JIT 与后台负载影响，单次 P95 在 3–40 ms 间波动（首个样本预热），均远优于 200 ms；B7 受磁盘负载影响约 0.8–1.4 s，中位数稳定达标。正式回归若引入性能断言建议放宽阈值。
