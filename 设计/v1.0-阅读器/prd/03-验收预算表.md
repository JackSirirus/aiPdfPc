## 约束与注记

| # | 约束 | 说明 |
|---|------|------|
| B1 | 扫描件搜索指标不适用 | 无文本层的扫描件 PDF 不支持全文搜索，指标 4/5 对扫描件无效。搜索功能仅对含文本层的 PDF 生效。 |
| B2 | XFA 表单 PDFium 不支持 | PDFium 仅支持 AcroForm 表单；XFA 表单（政府/银行常见）渲染为静态页面，交互字段不可用。forms 工具范围限 AcroForm。 |
| B3 | PDFium 全 API 非线程安全 | `fpdfview.h` 所有 API 均非线程安全（含 FPDFText_*）；渲染与搜索在并发下互相阻塞，必须使用全局单锁。指标 4 的锁等待时间包含此开销。 |
| B4 | native 内存对 GC 不可见 | PDFium 分配的 native 内存不受 .NET GC 管理；任务管理器/性能计数器不可靠，必须使用 working-set 差值法测量（指标 8）。 |
| B5 | 纹理尺寸上限 | 400% × 150 DPI = 5052px 超 4096px 纹理上限，需分块渲染或缩放限幅。指标 2 的 150 DPI 在高缩放时可能触发此限制。 |
| B6 | 密码内存驻留 | 会话密码驻留为标签内存会话（解锁一次后续免密），密码绝不进入阅读状态/最近列表/会话恢复持久化。不影响性能指标，但影响安全验收。 |
