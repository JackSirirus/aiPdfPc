# 01 工具通道映射表

> 判据来源：需求总结.md 第 39 行（四通道定义）、第 58 行（工具参数 UI 两种形态）、第 79 行（决策 16：复杂编辑工具临时标签）。
>
> 通道定义（需求总结.md:39）：
> - **起始页**：无 PDF 输入的工具，仅在无文档时展示。
> - **右抽屉**：单文件工具，内联参数面板（决策 7）。
> - **向导**（模态向导）：多文件或多步工具（决策 4）。
> - **临时标签**：复杂编辑工具，复用现有工具页，每标签页面实例缓存（决策 16）。
>
> 判据优先级（先匹配先得）：
> 1. 无 PDF 输入（extensions 不含 pdf）→ 起始页
> 2. 复杂选择/交互（edit/forms/crop）→ 临时标签
> 3. 多文件或多步（multiple=True 或 id="workflow"）→ 向导
> 4. 单文件 → 右抽屉
