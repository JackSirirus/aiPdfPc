# AIPDF 本机验证报告

验证时间：2026-09-05。环境：Apple Silicon、macOS 15.7.4、Swift 6.2.4、Python 3.14.6、PyMuPDF 1.28.2。依赖精确版本见 `requirements.lock.txt`。

## 自动验证

`tests/test_engine.py` 的 **27 组测试全部通过，无跳过**。每组包含若干真实文件断言，不仅验证函数是否返回成功。

覆盖：

- 合并顺序、同名表单字段独立保留、拆分分组、提取、删除、倒序、重复页面。
- 页码越界、非法范围、空白输出、非法坐标和放不下的文字。
- 旋转、裁剪，以及已经裁剪并旋转过的页面再次裁剪。
- 文字/图片水印、中文与英文文字、页码、图片/矩形/高亮及手写签名。
- AES-256 加密、错误密码拒绝、正确解锁、源文件 SHA-256 保持不变。
- 敏感文字从 MuPDF 与独立 pypdf 两种提取结果、元数据和输出原始字节中消失。
- 无损及图片压缩、损坏 xref 恢复、逐页图片导出与图片 PDF 回转。
- DOCX、PPTX、XLSX 真实文件生成与重新打开；LibreOffice 反向转换。
- PDF/A 导出与元数据标识检查（不等于 veraPDF 的完整标准验证）。
- 表单字段树、字段值、Widget 值和外观流一致；中文值、复选/列表/单选创建。
- 本地 HTML、真实 WebKit 渲染本机测试网页；对比 PDF/HTML、Markdown 表格。
- Apple Vision 扫描和 OCR 的真实系统服务，输出可搜索的文字。
- 多步骤流程，包括先加密再解锁；子进程 JSON 通信与第三方输出隔离。
- 取消时终止 Python Worker 及它启动的子进程。
- 已移除的摘要/翻译请求会被拒绝；工具目录保留 32 项；组件健康检查不连接模型服务。

### 环境发现

- 无机器级 Desktop Runtime（apphost 探测 Program Files 失败），自包含为唯一可行发行形态。
- LibreOffice 必须指向 `soffice.com`（console 子系统），`soffice.exe`（GUI 子系统）挂起不返回。
- ms-playwright `__dirlock` 为机器级共享文件，并发安装需等待。
- PS 5.1 `chcp 65001` + 重定向 = UTF-8 BOM 注入，破坏 JSON 解析。
